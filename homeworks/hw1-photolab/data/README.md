# data/ — ваши фотографии

Шесть файлов собственных фотографий (см. README задания, §2):

| Имя | Что снять |
|-----|-----------|
| `dark.jpg` | Недоэкспонированная сцена с деталями в тенях, например комната у окна. |
| `bright.jpg` | Сцена под тёплой или холодной лампой; белый/серый предмет для оценки баланса белого. |
| `object.jpg` | Яркий одноцветный предмет на пёстром фоне, целиком в кадре, с бликом и тенью. |
| `bg.jpg` | Отдельный фон для переноса предмета. |
| `poster.jpg` | Лист A4, плакат или этикетка под заметным углом; все четыре угла видны. |
| `text.jpg` | Страница с читаемым мелким текстом и небольшим наклоном. |

Для A4 пропорция ширина/высота = 210/297; для другого плаката нужны реальные
пропорции объекта. Координаты образца цвета и углов задаются после уменьшения.
Фотографии должны быть вашими: кадры курса используются отдельно в `sample_data/`.

Уменьшите до ≤ 2000 px по длинной стороне и ≤ 1.5 МБ каждый — например,
своей же командой `python photolab.py resize photo.jpg --scale 0.5 -o data/photo.jpg`.

В **этом** репозитории (ваш репозиторий Classroom) фотографии коммитятся: без них проверяющий не
повторит ваши числа. В репозитории курса папка `data/` под `.gitignore` — там лежит только этот файл.
